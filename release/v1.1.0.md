# 萌生 Mac 1.1.0 预览版

有事交给萌生，确认范围后，它会帮你推进，并在需要你决定时提醒你。

- **聊天也能交办**：直接说要办的事，或拖入文字、文件；萌生先理解需求，给出可以调整的计划，确认后开始。时间明确的提醒可以直接设置并撤销。
- **整理与交付**：使用你允许的资料整理内容、生成文件；任务列表里查看进度、补充要求、打开结果，文本结果可复制或原文存入灵感库。
- **交给本机 Codex**：需要运行命令或修改项目时，让 Codex 执行。萌生轻量跟进、依据已确认要求纠偏，重要取舍和额外批准交给你；也可打开对应 Codex 会话查看过程。
- **提醒更顺手**：可设置默认提醒时间，手动调整过的提醒不会随截止日期变动而被覆盖。无刘海 Mac 可通过菜单栏、快捷键和助手岛使用。

下载 `JotBloom-1.1.0-universal.dmg`，支持 macOS 13+、Apple Silicon / Intel。版本 **1.1.0**，构建 **1112**；SHA-256 见附件 `SHA256SUMS.txt`。

**升级前请备份。1.1.0 会升级数据库；降回 1.0.9 时需要退出萌生并恢复升级前备份，不能直接使用已升级的数据。** 升级后新增内容不会出现在旧备份中。历史版本：[Mac 1.0.9](https://github.com/FengLi-AI/JotBloom-Notch-Assistant/releases/tag/v1.0.9)。

助手使用你配置的模型接口；Codex 任务还需本机安装并登录 Codex，相关费用或额度由所用服务决定。提醒只在萌生运行时工作，重开后汇总错过的提醒。详见[数据与 AI](https://github.com/FengLi-AI/JotBloom-Notch-Assistant/blob/main/release/PRIVACY.md)。

更新时先退出旧版，将 App 拖入“应用程序”并选择“替换”。安装包采用 ad-hoc 签名，尚未经过 Apple 公证；操作见[安装说明](https://github.com/FengLi-AI/JotBloom-Notch-Assistant/blob/main/release/INSTALL.md)，安装包内也附有说明。
