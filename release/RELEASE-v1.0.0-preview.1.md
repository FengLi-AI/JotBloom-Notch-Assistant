# 萌生 V1.0 · 首个公开预览版

随手记录灵感、回看剪贴板、收藏常用提示词，和 AI 继续讨论想法。欢迎体验并反馈问题。

## 下载

下载附件 `JotBloom-1.0.0-preview.1-universal.dmg`，打开后将 App 拖入“应用程序”。不是源码 ZIP。应用版本 1.0.0，构建 1101，包含 arm64 和 x86_64。

SHA-256：`3e604f6d182bdf38f6ddac217fe967e24338129bde625ce0fe4ea6a42f14ffb6`。

## 使用前请注意

- macOS 构建目标为 13 及以上；最低系统、Intel 真机和完整新装/升级权限体验仍待更多验证。
- 未经过 Apple 公证，使用 ad-hoc 签名；首次启动可能受到系统拦截。请核实来源后按 [Apple 官方说明](https://support.apple.com/zh-cn/102445) 处理，不要关闭系统安全保护。
- 首次使用或权限状态变化时，钥匙串可能需要授权。没有“永久免授权弹窗”的保证。
- 更新前保存内容、退出旧版，并备份重要数据。不包含自动更新器。
- 当前安装包尚无专用应用图标。
- AI 需要自己配置兼容接口与 API Key，费用由服务商决定。非 AI 本地功能可独立使用。
