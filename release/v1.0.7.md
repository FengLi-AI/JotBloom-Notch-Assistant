# 萌生 Mac 1.0.7 · 文件中转站

把文件暂放在刘海，稍后拖出使用。基础功能继续免费、MIT 开源，无需登录或激活。

- **文件中转站**：仅保存原路径引用，不复制源文件到萌生数据目录。拖出时使用原文件，可交给支持文件拖放的应用。
- **刘海快速收录**：拖入时提示“松手即可放入中转站”；成功后显示确认、彩色描边与小伙伴反馈，不自动弹出面板。新收录文件放在最前面。
- **筛选与整理**：按图片、文档、视频、音频、压缩包、文件夹等类型筛选，可叠加日期条件；支持网格排序、批量选择、移除、撤销及清空确认。移除和清空均不删除源文件。
- **更自然的拖动**：排序只保留一个虚线占位，其他文件平滑让位；拖出后不留下空位，目标应用接收后自动收起面板。
- **界面与动画修复**：修复刘海点击后面板不显示、收起前闪动；中转站加入双向自适应动画。剪贴板、提示词和灵感库默认使用普通边框，点击时给予轻微蓝色反馈。
- **导航调整**：默认顺序为灵感、灵感库、剪贴板、提示词、中转站、对话；搜索和设置固定最右。⌘1～⌘6 跟随实际顺序，默认 ⌘5 打开中转站；⌘F 搜索、⌘, 设置。旧默认顺序更新，自定义顺序保留。

## 安装与升级

下载 `JotBloom-1.0.7-universal.dmg`，支持 macOS 13+，包含 Apple Silicon / Intel 架构。版本号 1.0.7，构建号 1109。打开后将「萌生｜JotBloom.app」拖入「应用程序」。SHA-256 见附件 `SHA256SUMS.txt`。

升级前保存内容、退出旧版并备份重要记录。沿用原应用标识和数据位置，首次启动自动升级数据库；**旧版不能直接读取升级后的数据库，降级需恢复升级前备份**。

安装包使用 ad-hoc 签名，尚未经过 Apple 公证，系统可能提示核实来源，请按系统指引安装。最低系统及 Intel 真机兼容性仍需更多反馈。本次仅发布 Mac 版。

## 使用边界

中转站不是文件备份：源文件删除、替换或临时文件被来源应用清理后，引用可能失效。云盘文件需先下载到本机。刘海收录及小伙伴反馈需要带内置刘海屏的 Mac，也可直接向已打开的中转站拖入文件。

已实测确认中转站文件可拖入微信输入框；不同应用、文件类型及批量拖放的兼容性仍需持续反馈。AI 功能继续由用户自行配置 API。
