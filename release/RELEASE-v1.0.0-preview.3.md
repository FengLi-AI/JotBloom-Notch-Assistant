## 更新内容

- **首次启动先选存储位置**：没有现有数据的新用户，先选择父目录，再在其中创建独立的 `JotBloom` 数据目录；取消则退出。选择完成前不建业务库、不启动剪贴板采集。
- **已有用户保留原位置**：升级继续使用现有数据；空库也会保留。目录失联或定位记录损坏时进入恢复流程，不悄悄建立新空库。
- **快捷键录制更明确**：点击录制后接收面板键盘输入，按修饰键显示预览；成功立即更新并保存，无效或注册失败显示反馈并保留旧组合。Esc 取消录制，切页或失焦时结束录制。

快捷键可先尝试 **Control + Option + K**。Command + Space、Control + Space 通常用于系统功能，可能被系统先接收；仅 Shift，或 Z + Space 这样的两个普通键不支持。此次没有绕过系统快捷键限制。

## 安装与测试

保存内容并正常退出旧版，保留重要数据与旧 App 备份，然后打开 DMG，把 **萌生｜JotBloom.app** 拖入“应用程序”，从应用程序启动并弹出 DMG。

**卸载旧 App 后再安装，只要保留了原数据，就仍属于升级，不会再次弹出首次目录选择。** 已有用户更改目录请使用“设置 → 存储与隐私 → 选择新位置并迁移”。首次使用流程可在独立 macOS 测试账户验证，不要为测试删除正式数据库、定位文件或钥匙串。

本版保持应用标识、SQLite V7 和钥匙串服务标识。旧版若名为 `JotBloom.app`，请避免把两个 App 同时留在应用程序目录运行。
