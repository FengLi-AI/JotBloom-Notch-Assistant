# 萌生 Mac 1.0.4

这次更新带来深浅双主题，以及统一的字体、图标、按钮和间距。设置 → 通用 → 界面外观可切换，配色从按钮处圆形扩散，时长 1.5 秒；开启减少动态效果时使用静态切换。

- 使用 MiSans 字体、Tabler 线性图标，按钮描边 0.75pt、输入与设置面板描边 0.5pt。
- 保存灵感使用蓝色弥散渐变，AI 探讨使用紫色；浅色版本使用独立的较亮配色。
- 统一底部 16pt 间距，优化二级导航、滚动条与展开动效。
- 对话／搜索进入时自动展开；回到其他标签时恢复此前普通页面的大小。
- 默认系统提示词采用五段结构，常规回复尽量控制在 150 字以内。精确匹配旧默认的设置升级，自定义提示词和历史会话快照保留。
- 对话、标题、分类、整理统一携带固定产品约束；它们是模型指令，不保证任何自带模型都能完全遵守。

验证：365 项 XCTest、90 项隔离原生检查通过。Universal DMG 的 arm64 / x86_64 架构、签名完整性、挂载内容及版本 1.0.4 / build 1106 已核对。未将开发机检查扩大为所有设备的验收结论。

需要 macOS 13+。安装包使用 ad-hoc 签名，尚未经过 Apple 公证。请先退出旧版，再从 DMG 将 App 拖入应用程序；保留重要数据备份。
