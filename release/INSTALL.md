# 萌生安装说明

Mac 版本 1.0.3 / 构建 1105；Windows 版本 1.0.3 测试版。

## Mac 安装

1. 从本项目 GitHub Releases 下载 DMG；可使用 `shasum -a 256 安装包路径` 对照附件 SHA256SUMS.txt。
2. 打开 DMG，将 萌生｜JotBloom.app 拖入 Applications（应用程序）。
3. 从应用程序目录启动萌生，然后弹出磁盘映像。
4. 新用户先选择保存位置，萌生会在所选文件夹下创建独立的 `JotBloom` 数据目录；取消则退出。已有用户沿用原位置。
5. 默认快捷键为 Option + Space，可在设置中修改，例如 Control + Option + K。仅 Shift 或两个普通键不支持；系统占用的组合可能无法录制。

本版内置正式图标并统一显示名称。从 preview.1 升级时，先退出旧版，把旧的 JotBloom.app 移到自己的备份位置，再安装新版，避免应用程序目录同时保留两份。不要删除数据库或钥匙串；应用标识、数据格式与钥匙串服务标识没有改变。

## 系统安全提示

安装包未经过 Apple 公证，采用 ad-hoc 签名。首次启动可能受到 macOS 安全保护拦截。仅在核实来源并信任软件后，根据 [Apple 官方说明](https://support.apple.com/zh-cn/102445) 在系统设置中处理。不建议关闭 Gatekeeper，不保证所有受管理设备都能运行。

系统启动确认与钥匙串授权是不同的提示。AI 需要自己的 API Key，首次使用、撤销权限或升级后可能需要重新授权。不要将 API Key 发给作者或提交到 Issues。

## 升级与数据

先保存未完成内容、正常退出旧版，备份重要记录和旧 App，再替换安装。请在设置里确认实际的数据保存位置，不要盲目删除目录。

卸载 App 不会自动删除本地数据、备份或钥匙串条目，因此保留数据后重装属于升级，不会重新触发首次目录选择。若要改变已有保存位置，请使用设置中的迁移功能；首次使用流程可在独立 macOS 测试账户验证，不要删除正式数据来模拟新装。暂不提供自动更新和一键彻底卸载；如需清理，请先确认具体数据位置及是否保留备份。

## 兼容性范围

构建目标 macOS 13 及以上，包含 Apple Silicon 与 Intel 架构。最低系统、Intel 真机及完整的新装/重启/覆盖升级权限矩阵仍待更多验证。当前属于公开预览版，重要数据请保留备份。

## Windows 安装

适用于 Windows 10 22H2 / Windows 11，Intel / AMD 64 位。下载 EXE 后双击安装，首次启动时选择数据保存位置。默认快捷键 `Ctrl+Alt+Space`，也可以将鼠标紧贴屏幕顶部中央，提示条出现后点击打开。

运行组件已包含，无需另装 .NET。安装包尚未签名，系统可能提示核实来源；请按系统指引操作。升级和卸载前从托盘退出萌生。卸载会保留用户数据、设置及加密密钥，重装继续使用原保存位置。
