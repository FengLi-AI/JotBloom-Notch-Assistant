# 萌生安装与更新说明

Mac 1.0.7（构建 1109）；Windows 保留 1.0.3 测试版。

新增文件中转站：保存原路径引用，拖出使用；支持类型与时间组合筛选、排序和批量移除，不复制或删除源文件。

## 一、首次安装

1. 从萌生官网或 GitHub Releases 下载 DMG，双击打开安装包。
2. 将“萌生｜JotBloom.app”拖到旁边的 Applications（应用程序）文件夹，等待复制完成。
3. 打开访达（Finder），在左侧选择“应用程序”，找到“萌生｜JotBloom”并双击打开。也可在访达按 Shift + Command + A 打开应用程序目录。
   请从这里启动，不要直接运行安装包中的 App。安装后不一定会自动出现在程序坞（Dock），找不到图标时以访达中的“应用程序”为准。
4. 若出现安全提醒，按下面“三、系统拦截时如何打开”操作。
5. 成功启动后，新用户选择数据保存位置；已有数据的用户沿用原位置。随后可在访达中弹出“萌生 JotBloom”磁盘映像。

## 二、版本更新（直接替换）

1. 保存尚未完成的内容，退出正在运行的萌生，并提前备份重要记录。仅收起面板不等于退出 App。
2. 打开新下载的 DMG，把“萌生｜JotBloom.app”拖入 Applications（应用程序）。提示已存在同名应用时，选择“替换”，等待完成；如要求管理员密码，按系统提示操作。
3. 回到访达 → 应用程序，找到萌生并双击打开。更新后也可能再次出现安全提醒，继续按下一节处理。
4. 更新会沿用原来的数据位置和应用标识，不需要删除记录或重新创建数据目录。
   本版本会升级数据库结构，旧版本不能直接读取升级后的数据库；如需降级，请使用升级前的备份。

## 三、系统拦截时如何打开（首次安装、更新后均适用）

本安装包采用 ad-hoc 签名，尚未经过 Apple 公证。仅在确认从官方渠道下载且文件未被篡改后操作。

1. 先在访达 → 应用程序中双击萌生，让系统显示提醒。
2. 如果提示“无法验证开发者”或“Apple 无法检查是否包含恶意软件”，点击“完成”“好”或关闭提醒（不同 macOS 的按钮名称可能不同），不要选择“移到废纸篓”。
3. 打开系统设置 → 隐私与安全性，向下滚动至“安全性”区域，找到萌生被阻止打开的提示，点击“仍要打开”。
4. 按系统提示验证身份；再次出现确认框时，点击“打开”。
5. 如果萌生没有自动启动，再回到访达 → 应用程序，双击“萌生｜JotBloom”。之后通常可直接打开。

找不到“仍要打开”：先回到访达中的“应用程序”再次尝试打开萌生，再查看系统设置。受公司管理的 Mac 可能由管理员限制此选项。
如果提示“将损坏你的电脑”或“App 已损坏”，不要把它当成上面的普通开发者提醒；请重新从官方来源下载并核对校验值，必要时反馈问题。
不需要关闭系统安全保护，也不需要运行终端解除隔离命令。
[Apple 官方说明](https://support.apple.com/zh-cn/102445)
[官方下载](https://github.com/FengLi-AI/JotBloom-Notch-Assistant/releases/latest)

卸载 App 不会自动删除本地数据或钥匙串条目。请在设置中确认实际保存位置；需要更换位置时使用迁移功能，不要删除正式数据来模拟首次安装。

## 四、使用与兼容性

支持 macOS 13+，包含 Apple Silicon 和 Intel 架构。桌宠、刘海拖入和纸条提醒需要带内置刘海屏的 Mac；其他电脑仍可使用原有记录、剪贴板、提示词、AI 对话和搜索。
默认快捷键：Option + Space；也可在设置中修改。
AI 使用自己的 API，费用由所选服务商收取。API Key 使用系统钥匙串保存；钥匙串授权与上述系统启动确认是不同的提示。
Codex 提醒只在本机识别新增完成事件，可随时在设置中关闭。

## Windows 安装

适用于 Windows 10 22H2 / Windows 11，Intel / AMD 64 位。下载 EXE 后双击安装，首次启动时选择数据保存位置。默认快捷键 `Ctrl+Alt+Space`，也可以将鼠标紧贴屏幕顶部中央，提示条出现后点击打开。

运行组件已包含，无需另装 .NET。安装包尚未签名，系统可能提示核实来源；请按系统指引操作。升级和卸载前从托盘退出萌生。卸载会保留用户数据、设置及加密密钥，重装继续使用原保存位置。
