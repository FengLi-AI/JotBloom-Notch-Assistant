# 萌生 Mac 1.0.5 · 六位小伙伴

本次新增功能全部免费，源码与原创角色按 MIT 开源，无需购买或激活。

- 新增垂垂、云团、嘟角、墨墨、栗栗、暮暮六个像素小伙伴，支持常驻或偶尔出现。
- 新增呼吸、好奇、打盹、精神好、累趴、接灵感、满足和递纸条等动作；打开萌生面板时，小伙伴会让出位置。
- 新增拖入刘海收录灵感：选中文字，拖到刘海本体松手，原文保存到灵感库。
- 新增本机 Codex 后台完成提醒：任务完成后递来纸条，来源应用在前台时不打扰。可在设置中关闭，不上传或保存会话正文。
- 设置新增「小伙伴」，六角色以两行展示，可调整陪伴方式、出现频率、拖入收录和提醒开关。
- 官网新增小伙伴体验页，支持选角色、看动作及演示拖入和完成提醒，并更新 Mac 安装包下载入口。

[官网](https://fengli-ai.github.io/JotBloom-Notch-Assistant/) · [网页体验](https://fengli-ai.github.io/JotBloom-Notch-Assistant/companions/)

## 安装与兼容

Mac 安装包：`JotBloom-1.0.5-universal.dmg`，支持 macOS 13+，包含 Apple Silicon / Intel 架构。打开后将「萌生｜JotBloom.app」拖入「应用程序」。升级前保存内容并退出旧版，保留重要数据备份；应用标识与数据格式保持不变。

桌宠、刘海拖入和纸条提醒需要带内置刘海屏的 Mac。其他电脑仍可使用原有功能。Windows 保持 1.0.4 测试版，本次未发布 Windows 新版。

安装包使用 ad-hoc 签名，尚未经过 Apple 公证，系统可能提示核实来源；请按系统指引安装。最低系统及 Intel 真机兼容性仍需更多反馈。下载文件的 SHA-256 见附件 `SHA256SUMS.txt`。

网页演示不连接本机 Codex，拖入文字仅在当前页面暂存，刷新后清空。AI 功能继续由用户自行配置 API。
