# 数据与 AI 使用说明（发布前草稿）

尚未公开发布。内容根据当前实现整理，正式发布前需与对应版本逐项复核；不是对所有第三方模型服务的隐私承诺。

## 本地保存

灵感、提示词、对话、草稿及剪贴板历史保存在本机指定目录，设置保存在本机。API Key 存入系统钥匙串，而不是写进普通配置文件。钥匙串保护不等于数据库内容已经端到端加密。

剪贴板监听在当前新配置中默认开启，可在设置里关闭。关闭监听不自动删除已有历史；清空历史与关闭监听是两个不同操作。不要把密码等敏感信息长期保存在剪贴板历史中；产品无法保证识别所有敏感内容。

## 何时发送到模型接口

| 功能 | 发送范围 |
| --- | --- |
| 测试连接 | 固定测试文字，不发送用户记录 |
| 新提示词 AI 标题 | 条件满足时发送提示词正文最多前 2000 字符生成短标题；保存按钮已有范围提示 |
| 灵感 AI 分类/短标题 | 用户开启灵感 AI 后发送受限文本片段；该开关默认关闭 |
| AI 对话 | 用户发送的消息及必要对话上下文、系统提示词等请求内容 |
| 整理为灵感 | 用户主动整理的已完成对话内容，按当前长度/轮次规则选择 |

数据发送给用户自己配置的服务商，费用、留存和训练使用规则由该服务商决定。配置第三方转发地址时，转发服务也可能接触请求内容。请勿在不了解服务政策时发送敏感数据。

## 分发与网站

计划通过 GitHub Pages 和 Releases 提供官网与下载；访问官网或下载文件会与 GitHub 建立连接。不把“本地优先”写成“整个产品从不联网”。本阶段未增加账号系统、产品分析脚本或遥测。

保存位置迁移可能保留原目录副本；删除应用不等于删除所有历史数据、备份或钥匙串条目。正式卸载与数据清理指引应列出具体范围，并由用户主动操作。
