# 萌生 Mac 1.0.9 · 更自然的展开与收起

面板从顶部中央连续展开，带有轻微回弹，收起时平顺回到刘海。快速连续开合会接续当前形状和速度，文字在动画结束后恢复原生尺寸与清晰度。原有面板尺寸、功能入口和减少动态效果设置保持可用。

下载 `JotBloom-1.0.9-universal.dmg`，支持 macOS 13+、Apple Silicon / Intel。版本 1.0.9，构建 1111；SHA-256 见附件 `SHA256SUMS.txt`。

更新时先退出旧版，将 App 拖入“应用程序”并选择“替换”。从 1.0.7 或 1.0.8 升级不涉及数据库结构变更。安装包采用 ad-hoc 签名，尚未经过 Apple 公证；系统确认步骤见[安装说明](https://github.com/FengLi-AI/JotBloom-Notch-Assistant/blob/main/release/INSTALL.md)，安装包内也附有说明。

动效参考 [DynamicNotchKit](https://github.com/mrkai77/DynamicNotchKit/tree/cd0b3e52d537db115ad3a9d89601f20e0bee8d27) 的顶部锚定、肩部曲线与内容过渡，并按本次选定参数独立实现；未直接集成该库。MIT 许可及署名随 App 附带。
