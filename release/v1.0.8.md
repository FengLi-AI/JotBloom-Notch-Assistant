# 萌生 Mac 1.0.8 · 修复外接屏误触发

修复无刘海外接屏顶部的隐形热区误触发：点击与拖入仅在内置屏的真实刘海区域响应。外接屏仍可通过快捷键或菜单栏入口打开萌生。

下载 `JotBloom-1.0.8-universal.dmg`，支持 macOS 13+、Apple Silicon / Intel。版本 1.0.8，构建 1110；SHA-256 见附件 `SHA256SUMS.txt`。

更新时先退出旧版，将 App 拖入“应用程序”并选择“替换”。从 1.0.7 升级不涉及数据库结构变更。安装包采用 ad-hoc 签名，尚未经过 Apple 公证；首次打开或更新后的系统确认步骤见[安装说明](https://github.com/FengLi-AI/JotBloom-Notch-Assistant/blob/main/release/INSTALL.md)，安装包内也附有说明。
