# 数据与 AI 使用说明

适用于 Mac 1.1.0；助手功能仅在 Mac 版提供，现有 Windows 版本的数据规则保持不变。第三方模型的费用、数据留存和训练使用政策由你选择的服务商决定。

## 本机保存

新用户首次启动先选择数据位置；选择完成前不创建业务库、不启动剪贴板采集。灵感、提示词、对话、草稿及剪贴板历史保存在该位置下的独立 JotBloom 目录，设置和位置定位记录保存在本机。已有用户沿用原位置，可在设置中迁移。Mac 的 API Key 使用系统钥匙串；Windows 使用 DPAPI CurrentUser 加密文件，密钥不以明文写入普通配置或数据库；这不代表所有记录都已加密。

剪贴板监听默认开启，可在设置中关闭。关闭监听不等于删除历史，清空记录需要单独操作。软件不能保证识别全部敏感内容，请不要长期保存密码等信息。

## 文件中转站

中转站在本机保存文件路径、定位书签、类型、加入时间和排序等引用信息，不将源文件复制到萌生数据目录，也不自动上传文件或发送给 AI。拖出时交给目标应用的是原文件 URL；后续发送或上传由目标应用处理。移除和清空只删除引用，不删除源文件。原文件被删除、替换、移到无法定位的位置，或临时文件被来源应用清理后，引用可能失效。

## 何时向你配置的模型接口发送内容

| 功能 | 内容范围 |
| --- | --- |
| 测试连接 | 固定测试文字 |
| 提示词短标题 | 条件满足时发送正文受限片段，最多前 2000 字符 |
| 灵感分类与短标题 | 开启灵感 AI 后发送受限片段；该开关默认关闭 |
| AI 对话 | 发送的消息、必要上下文及系统提示词 |
| 整理为灵感 | 主动整理的已完成对话内容，按长度及轮次限制选取 |

配置第三方转发接口时，该转发服务也可能接触请求内容。请了解服务商政策后再发送敏感信息。

## 版本检查

仅在你点击“关于 → 检查最新版本”时，请求 GitHub 的公开版本列表；不会上传灵感、剪贴板、对话或 API Key，不使用 GitHub 登录凭证。GitHub 会接收到正常网络请求信息（如 IP）。不在后台自动检查，也不自动下载或替换安装。点击官网、邮箱或社交主页会交由浏览器/邮件应用打开。

## 网站与下载

官网由 GitHub Pages 托管，安装包由 GitHub Releases 提供。访问、下载或打开仓库链接会与 GitHub 建立连接。官网不接入额外的产品分析脚本，不要求账号注册，也不通过网站收集 API Key。

点击下载后的 Star 提示为自愿支持，不检测你是否点星，不限制下载。

## 数据清理与联系

迁移保存位置可能留下原目录副本。卸载应用不等于删除历史、备份、钥匙串条目或 Windows 加密凭证。清理前请确认保存位置并备份重要数据。

## Mac 小伙伴与完成提醒

小伙伴在本机绘制，不需要联网。拖入刘海的文字使用现有灵感保存流程；若开启灵感 AI，仍遵循前述模型调用说明。

Codex 完成提醒读取你指定的本机 Codex sessions 目录，解析来源元数据和新增 task_complete 事件。不会修改 Codex 文件，不保存或上传会话正文，也不读取 API Key。首次启动、唤醒时不补发旧任务；来源应用在前台、中断与子代理结束不提醒。可在设置 → 小伙伴中关闭提醒或更改目录。

官网小伙伴体验只演示动作。拖入的文字以纯文本在当前页面显示，不上传、不跨刷新保存；网页不连接本机 Codex，也不请求目录访问权限。

## Mac 助手与 Codex 任务

任务、确认的范围、提醒、进度、批准记录和结果路径保存在本机。发送助手消息时，意图判断会把当前消息和必要的最近一轮对话发送给你配置的模型，用于区分聊天、办事和记录；理解任务还会使用必要的对话上下文及附件名称。普通聊天、意图判断失败后的普通回答仍遵循上面的模型发送说明。保存灵感不经过意图判断。

执行任务只使用确认的目标、完成标准、补充和允许的资料；未勾选的聊天原文不进入执行请求。开启“自动找相关资料”允许检索本机灵感和提示词，不包含剪贴板历史。读文件或用户提供的链接时，可读文本会在已确认的范围内提供给模型；任务资料单次最多 8000 字符、累计最多 40000 字符。萌生本身的链接读取拒绝本机、内网地址，不自动跟随页面里的其他链接。

确认派给 Codex 后，任务说明、已确认要求和允许使用的灵感/提示词正文交给本机 Codex；文件只发送路径，由 Codex 自行读取。内容按 Codex 所用服务的规则处理、消耗你的 Codex 额度。萌生不读取或保存 Codex 登录令牌，不替你登录，不修改 Codex 全局配置；Codex 自身会按其机制保存会话。

轻量监督会把已确认目标、完成标准、最近补充，以及 Codex 最近最多四段公开阶段汇报、计划和部分文件变化路径发给你配置的主模型。监督状态保存在本机；不把命令输出、推理流或批准详情送入监督模型。监督可能遗漏偏离或误判，不能代替结果验收；自动纠偏只重申已有要求，不追加权限。

未经额外用户批准，Codex 写入限于任务结果文件夹和明确选定的工作文件夹；范围外批准交给用户，明确批准后可能突破原写入范围。这个限制不是读取白名单：Codex 可能读取勾选资料之外的本机文件；允许联网后，可访问的网站也不限于你提供的链接。请尽量选择小范围的工作文件夹。额外批准由用户决定，任务模型不能替你批准；“本次任务内允许”不写入长期规则。当前轮次的网络权限只能依据已确认联网范围追加。

萌生任务不继承 Codex 的插件、MCP 工具和 app 连接，未允许联网时关闭内置搜索。应用用无任务输入的临时会话检查工具状态，并设置任务会话内覆盖；无法确认隔离时停止派活，不更改用户配置文件。完整过程通过“在 Codex 中打开”交给 Codex 客户端展示，能否实时跟随由客户端决定。

安静模式只影响提醒的展示，不停止任务或模型调用。提醒仅在萌生运行时工作；退出或关机时不唤醒系统，重开后汇总错过的提醒。结果文件保存在所选目录；删除任务、退出、停止、失败或卸载应用都不自动删除已交付文件。助手不请求辅助功能、屏幕录制或全盘访问权限。

## 升级与降级

Mac 1.1.0 会升级任务和提醒所需的本地数据库结构。升级前请保留备份；降回 1.0.9 必须恢复升级前的数据备份，不能直接使用已升级的数据库。恢复旧备份不会保留升级后新增的记录。
