# 萌生 Windows · 1.0.2 测试版

新增 Windows 客户端，适配 **Windows 10 22H2 / Windows 11，Intel / AMD 64 位**。

- 从屏幕顶部中央提示条或 `Ctrl+Alt+Space` 呼出，快捷键可自定义。
- 灵感记录、剪贴板历史、提示词、灵感库、搜索和 AI 对话均已接入。
- 首次启动选择数据保存位置，支持备份、迁移与完整设置。
- 软件免费使用；AI 功能使用你自己的接口，第三方服务可能收费。
