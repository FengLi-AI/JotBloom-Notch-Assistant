## 复验入口

### 刘海点击后主界面透明（2026-09-23 修复）

- 原因：打开时重置展开状态，排队的尺寸更新随后取消淡入计时器，窗口透明度停在 0；关闭时的不透明快照导致界面闪现。
- 修复：生命周期重置不再排队调整尺寸，过期的尺寸更新作废；调整尺寸时延续淡入，关闭快照继承当前透明度。
- 回归：修复前复现首次打开、五个默认页面及快速重开透明；修复后 22 项原生窗口检查全部通过，覆盖七个默认页面、快速开关、拖入预览与减少动态效果。383 项自动测试通过。
- 关联复查：中转站原生视图与拖放回调 27 项、旧页面展开／收起动画 37 项均通过；Debug 构建与仓库边界检查通过。
- 检查调用真实刘海激活回调，并验证窗口透明度、尺寸和快照清理；不替代用户手动点击物理刘海的验收。

在隔离 Debug 数据目录下同时设置 `JOTBLOOM_UI_REVIEW=1`、`JOTBLOOM_REVIEW_SMOKE=1`、`JOTBLOOM_PRESENTATION_SMOKE=1` 可运行上述窗口回归检查，完成后自动退出。

### 常规与中转站检查

常规测试：`xcodebuild -project JotBloom.xcodeproj -scheme JotBloom test CODE_SIGNING_ALLOWED=NO`。

Debug 原生检查使用 `JOTBLOOM_DEBUG_DATA_DIRECTORY` 指向独立测试库、`JOTBLOOM_FILE_SHELF_REVIEW` 指向测试文件目录，并设置 `JOTBLOOM_FILE_SHELF_PROBE=1`。检查会输出 `FILE_SHELF_REVIEW` 结果与测试目录旁的截图；仅在隔离模式启用。请至少准备 8 个测试文件／文件夹，不要指向个人资料。

## 试用反馈调整（2026-09-23）

- 顶部按钮区域不变，常规尺寸显示图标与完整中文；极窄尺寸优先中文，不再只剩图标或省略号。复查深／浅色与 85%／100%／120% 尺寸。
- 排序先移除被拖项的原位置，再留下唯一目标占位；占位为内缩虚线框，文件在 220 ms 内连续让位。拖出后恢复完整排列；本地排序等待保存完成再退出预览，避免先闪回旧顺序。
- 刘海文件收录复用文字收录的反馈动画，文件与文字开关独立；失败不触发成功描边或收录动作。小伙伴与文字收录原生回归 81 项通过，窗口显示回归 22 项通过。
- 剪贴板未捕捉的原因是此前手动试用误用了自动测试的命名剪贴板。新增 Debug 手动开关 `JOTBLOOM_MANUAL_SYSTEM_CLIPBOARD=1`，允许独立测试数据库连接系统剪贴板；自动回归默认仍用命名剪贴板，避免改动用户正在复制的内容。

## 收起首帧闪动与中转站动画（2026-09-23）

- 三个内容页的闪动原因：展开状态已切换，但过渡布局下一轮事件才创建，先渲染一次收起布局，再回到展开布局开始动画。现在先同步保存视觉起点，窗口尺寸仍延后更新，兼顾原生网格稳定性。
- 中转站接入共同布局过渡，类型标签与分类栏渐变切换；文件坐标、卡片和图标大小使用面板的同一进度，反向操作从当前画面接续。
- 动画回归改用非空的合成剪贴板、提示词、灵感数据及测试文件；额外检查点击后的第一帧，并保存连续截图。数据库、截图均放在临时测试目录。
- 验证：383 项自动测试、89 项综合动画检查、22 项窗口开关检查通过；换行淡入淡出调整后再复查中转站 29 项动画和 36 项功能／布局检查，均通过。已查看收起首帧和中转站中间帧截图，确认没有先切到收起布局再回跳，也没有跨行卡片斜穿相邻卡片。

## 卡片反馈与默认导航（2026-09-23）

- 剪贴板、提示词、灵感库默认边框恢复普通样式；按下主内容按钮时淡蓝反馈，松开后淡出。方向键导航保留轻微定位提示，中转站批量选中样式保留。
- 默认顺序为灵感、灵感库、剪贴板、提示词、中转站、对话，搜索及设置固定最右。旧默认顺序迁移，自定义顺序保留；新保存的顺序不重复迁移。
- 验证：20 项导航与中转站相关测试、36 组深浅色／尺寸／展开状态布局检查通过；已查看三个内容页的实际截图，默认无蓝色选中框。Debug 构建与公开仓库边界检查通过。
