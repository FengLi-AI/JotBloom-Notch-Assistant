# 可选拓展接口

基础客户端通过 `ApplicationExtensionHost` 提供可选的界面与生命周期接口，独立构建时不加载任何拓展，也不依赖账号、许可或网络验证。

组合客户端可在自身 Info.plist 中设置 `JotBloomExtensionPrincipalClass`，指向随应用编译、实现 `ApplicationExtending` 的类。接口只提供设置视图、设置存储、面板显隐通知和面板/设置打开操作；不从网络下载或执行模块。

宿主在主线程启动、通知与停止模块，首次启动会同步面板状态。数据目录迁移重建对象图时，先停止旧模块，再创建实例绑定新的面板，避免旧闭包失效。模块需要在 `stop()` 中释放窗口、观察者和定时器。

具体拓展实现、专属素材和组装入口不属于此公开仓库。新增存储能力应另行提供通用接口，并继续复用基础版数据格式。
