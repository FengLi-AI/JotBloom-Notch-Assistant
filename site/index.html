下载前，花一点时间看看这些说明。

支持什么系统？

目前面向 Mac，构建目标为 macOS 13 及以上，包含 Apple Silicon 与 Intel 架构。最低系统和 Intel 真机兼容性仍待验收，支持范围与已知限制以发布说明为准。

后续计划支持 Windows。

不接入 AI，可以用吗？

可以。记录灵感、剪贴板历史、提示词管理和搜索可独立使用。自动命名、AI 对话等功能需要你自己的接口和 API Key，服务商可能收费。

数据和密钥会存在哪里？

记录保存在本机，保存位置可以调整。API Key 存入 macOS 钥匙串。使用 AI 功能时，必要内容会发送至你配置的服务，请留意敏感信息。

下载安装需要注意什么？

当前预览包未经过 Apple 公证。请从本项目 GitHub Releases 下载并核对校验值，按系统提示安装，不要关闭系统安全保护。首次使用或权限变化时，钥匙串可能需要授权。重要记录在升级或迁移前请先备份。
