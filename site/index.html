下载前，花一点时间看看这些说明。

支持什么系统？

支持 Mac 与 Windows。Mac 版面向 macOS 13 及以上，包含 Apple Silicon 与 Intel 架构；Windows 版面向 Win 10 22H2 和 Win 11，适用于 Intel / AMD 64 位电脑。

Mac 从刘海区域呼出；Windows 将鼠标紧贴屏幕顶部中央，提示条出现后点击呼出。两端也都支持快捷键。

不接入 AI，可以用吗？

可以。记录灵感、剪贴板历史、提示词管理和搜索可独立使用。自动命名、AI 对话等功能需要你自己的接口和 API Key，服务商可能收费。

数据和密钥会存在哪里？

新用户首次启动先选择数据保存位置；已有用户保留原位置，可在设置中迁移。Mac 的 API Key 存入系统钥匙串；Windows 使用当前用户的系统保护加密保存。使用 AI 功能时，必要内容会发送至你配置的服务，请留意敏感信息。

下载安装需要注意什么？

请从本项目 GitHub Releases 选择对应系统的安装包。Mac 打开 DMG 后，将萌生拖入“应用程序”；Windows 双击 EXE 完成安装。首次启动时，两端都会请你选择数据保存位置。

Mac 安装包尚未经过 Apple 公证，Windows 安装包尚未签名，系统可能提示核实来源。请按系统指引操作；升级前保留重要数据备份。
